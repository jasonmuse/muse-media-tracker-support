# Muse Media Tracker Support

Static support and privacy pages for Muse Media Tracker.

Use these URLs in App Store Connect after GitHub Pages is enabled for this repo:

- Support URL: `https://jasonmuse.github.io/muse-media-tracker-support/`
- Privacy Policy URL: `https://jasonmuse.github.io/muse-media-tracker-support/privacy.html`

GitHub Pages setup:

1. Open this repository on GitHub.
2. Go to Settings > Pages.
3. Set Source to `Deploy from a branch`.
4. Choose the `main` branch and `/ (root)`.
5. Save, then wait for GitHub Pages to publish.
